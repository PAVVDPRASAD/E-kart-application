# Arizon E-Commerce Frontend

A responsive and fully functional e-commerce frontend built with **React.js**, **Tailwind CSS**, and **React Context API** for state management. This project was created as part of the Arizon Assignment to demonstrate front-end development skills, responsive design, and integration with external APIs.

##  Features

-  Product listing with real-time data from [FakeStore API](https://fakestoreapi.com/)
-  Add to cart and remove from cart
-  Cart subtotal calculation
-  Responsive design for mobile, tablet, and desktop
-  Context API with `useReducer` for state management
-  Clean UI using Tailwind CSS

---

##  Technologies Used

- **React.js**
- **Tailwind CSS**
- **React Router DOM**
- **React Context API**
- **FakeStore API**
